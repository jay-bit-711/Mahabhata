# Mahabharatam

Cinematic manga of the epic. Twenty acts, Sanskrit / English / Telugu, on [mahabhatam.vercel.app](https://mahabhatam.vercel.app/).

Story lives in `src/data/parvas/`. The player only sees the chronicle.

Sync this folder on your Mac:

```bash
cd /Users/jay/Desktop/Mahabharatam
git checkout main
git pull origin main
npm install
```
